# promptshield-ko 프로젝트 계획서

LLM 앱 앞단에 붙이는 한국어·영어 프롬프트 인젝션 탐지 레이어

## 1. 개요

### 목표
- 무료 도구와 공개 데이터만으로 구축할 수 있는 오픈소스 보안 프로젝트
- 실제 포트폴리오에 넣을 수 있는 수준의 정량 평가와 배포 결과물 확보

### 차별화 포인트
- 한국어 인젝션 탐지: 공개된 탐지기와 데이터셋은 대부분 영어 중심이라, 한국어 성능을 측정하고 개선하는 것 자체가 기여가 됨
- 간접 인젝션 탐지: RAG 문서 안에 숨겨진 지시문 탐지
- 배포 형태 세 가지: pip 패키지, FastAPI 미들웨어, 프록시 서버

## 2. 아키텍처

```
사용자 입력 ─▶ [Input Guard] ─▶ LLM (Ollama) ─▶ [Output Guard] ─▶ 응답
                 │                                  │
                 ├─ 1단계: 룰 필터 (정규식, 키워드)    ├─ 시스템 프롬프트 유출 검사
                 ├─ 2단계: ML 분류기 (DeBERTa)       ├─ 민감정보(PII) 검사
                 └─ 3단계: 점수 결합 → allow/flag/block └─ 카나리 토큰 검사
                                │
                          [로그 DB + 대시보드]
```

### 설계 근거
- 룰 필터를 먼저 실행: 명백한 공격은 저렴하게 걸러 지연시간을 줄이고, ML 분류기는 애매한 케이스만 판단
- 카나리 토큰: 시스템 프롬프트에 무작위 문자열을 심어두고, 응답에 나타나면 유출로 판단

## 3. 기능 범위

### MVP (필수)
- 직접 인젝션 탐지: 지시 무시 요구, 역할 탈취, 탈옥 시도
- 룰 + ML 하이브리드 점수 계산
- Python API: `guard.scan(text)`
- FastAPI 미들웨어
- 평가 스크립트와 벤치마크 결과표

### 확장 (선택)
- RAG 문서 대상 간접 인젝션 탐지
- 출력 측 시스템 프롬프트 유출 및 PII 검사
- 탐지 로그 대시보드 (Streamlit)
- 우회 기법 대응: Base64 인코딩, 유니코드 동형문자, 한글 자모 분리 등을 정규화한 뒤 검사

## 4. 데이터

| 용도 | 소스 |
|---|---|
| 영어 인젝션 | HuggingFace `deepset/prompt-injections`, Lakera gandalf 데이터셋, 탈옥 분류 데이터셋 |
| 정상 문장 | 일반 대화·질의 데이터셋 (영어/한국어) |
| 한국어 인젝션 | 직접 구축: 영어 공격 문장 번역·변형 + 직접 작성 |

### 구축 원칙
- 한국어 데이터셋 500~1,000건 구축, 구축 방법을 문서화 (프로젝트 핵심 기여)
- 오탐 테스트용 하드 네거티브 세트 별도 구성
  - 예: "보안 수업에서 프롬프트 인젝션이 뭔지 설명해줘"
- 데이터셋별 라이선스 확인 후 README에 명시
- 레포에는 원본 데이터 대신 다운로드·구축 스크립트만 포함

## 5. 모델

| 단계 | 내용 |
|---|---|
| 베이스라인 | 공개 탐지 모델(ProtectAI DeBERTa 기반 분류기, Meta Prompt Guard 계열)의 한국어 성능 측정 |
| 파인튜닝 | 다국어 모델(mDeBERTa-v3-base 또는 KLUE 계열), Colab 무료 T4 사용 |
| 경량화 | ONNX 변환 후 CPU 추론, 지연시간 측정 |

베이스라인의 한국어 성능 저하 수치가 프로젝트의 문제 정의 근거가 됨.

## 6. 평가

### 지표
- 언어별(한/영) Precision, Recall, F1
- 오탐률: 정상 문장을 공격으로 잘못 판단한 비율 (실서비스에서 가장 중요)
- 우회 공격 세트 탐지율
- 평균 및 p95 지연시간 (CPU 기준)

### 비교 대상
- 룰 단독
- 공개 모델
- 자체 파인튜닝 모델
- 하이브리드 (룰 + 자체 모델)

## 7. 디렉터리 구조

```
promptshield-ko/
├── promptshield/
│   ├── __init__.py
│   ├── guard.py            # 통합 API
│   ├── rules/              # 정규식, 키워드 룰
│   ├── normalize.py        # 인코딩·유니코드 정규화
│   ├── classifier.py       # ML 추론 (ONNX)
│   ├── output_guard.py     # 유출·PII 검사
│   └── integrations/
│       └── fastapi.py      # 미들웨어
├── server/                 # 프록시 서버 (FastAPI)
├── training/               # 학습 노트북, 스크립트
├── data/                   # 데이터 구축 스크립트
├── eval/                   # 벤치마크 스크립트, 결과
├── examples/               # Ollama 챗봇 데모
├── tests/
├── Dockerfile
└── README.md
```
